# CV metni

**HeaderGuard — HTTP Güvenlik Başlığı Analiz Aracı**  
TypeScript, Node.js, HTTP, CSP, HSTS, GitHub Actions

[GitHub](https://github.com/busrabuseucar/header-guard) · [Canlı demo](https://header-guard-buse.sleek-brush-8818.chatgpt.site)

> AI desteğiyle, HTTP yanıt başlıklarını altı temel kuralla inceleyen web ve CLI aracı geliştirdim. CSP/HSTS değerlendirmesi, tekrarlı başlıkların işlenmesi, hassas başlık değerlerini dışa aktarmayan JSON raporları ve otomatik regresyon testleri ekledim.

**Kısa sürüm:**

> TypeScript ile yerel HTTP güvenlik başlığı analizi; ortak web/CLI motoru, açıklamalı bulgular ve ham veri içermeyen raporlar.

**İngilizce:**

> Built an AI-assisted TypeScript browser and Node.js CLI tool for limited HTTP response header reviews. Implemented six checks covering CSP, HSTS and related headers, privacy-preserving JSON reports, and automated regression tests.

CV'de **Projeler** bölümüne koy. GitHub ve herkese açık demo bağlantılarını ekle. “Penetrasyon testi gerçekleştirdim”, “XSS'i önledim” veya “sitelerin güvenliğini doğruladım” yazma; bu araç bunları yapmıyor. Teknik iddiaları kodu ve testleri açıklayabildiğin kapsamda kullan.
